## 🚀 projects

### 🏎️ [F1Dash](https://github.com/xndrncp08) — AI-Powered F1 Analytics & Prediction Platform
> **Next.js · TypeScript · React Query v5 · Tailwind CSS · Recharts · Groq (Llama 3) · OpenF1 API**

A full-stack F1 analytics platform with a weighted prediction engine and an AI chatbot ("Nacho Bot") that reasons over live prediction data to answer race questions. Upgraded the prediction model from 4 to 8 factors, with radar/distribution charts to keep the expanded output readable, and a visual race grid for fast navigation across hundreds of historical sessions.

---

### 🚌 [WMBA — Where My Bus At?](https://github.com/xndrncp08)
> **React · Vite · Node.js · Express · Prisma · PostgreSQL · Docker**

A full-stack Calgary Transit tracker built independently with no spec — live bus positions on a map with real-time arrival predictions, structured from raw GTFS real-time feeds through a Prisma/PostgreSQL data layer, Dockerized for consistent deployment.

---

### 💊 BMR Pharmacy — Sales Tracker & Website
> **React · Node.js · Express · PostgreSQL · Ollama (local LLM)**

Designed and shipped a full-stack sales dashboard, still in daily production use, that replaced a family pharmacy's pen-and-paper tracking with live revenue dashboards and automated reporting. Separately built the pharmacy's customer-facing website, integrating Ollama to run a local LLM for an AI assistant feature with no third-party API dependency.
