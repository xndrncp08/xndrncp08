### 🎸 [Resoniq](https://github.com/xndrncp08/Resoniq) — Guitar Tone Analyzer
> **Next.js 16 · React 19 · TypeScript · FastAPI · Librosa · PostgreSQL · Prisma · Docker**

Drop in a song, get a starting-point guitar tone back — amp, cab, pedal chain, EQ, gain, pickup position. Librosa pulls the spectral data, a rule-based engine figures out the gear, and Claude can optionally write up the recipe. The UI is a multi-window desktop-style workspace (drag, resize, stack) with a WebGL spatial mode, and you can save your tones to a personal library.

### ⚡ [Overclocked](https://github.com/xndrncp08/Overclocked) — F1 Telemetry Stream Processor
> **TypeScript · Node.js · RxJS · DuckDB · SharedArrayBuffer · Ink · Vitest**

A telemetry pipeline built for speed: ~10k UDP packets/sec at sub-20ms end-to-end latency. Worker thread ingests into a lock-free shared-memory ring buffer, a compact 80-byte binary format keeps payloads ~3x smaller than JSON, RxJS handles rolling-window analytics and anomaly detection, DuckDB stores it, and a terminal dashboard (Ink) shows it all live.
